## 8. Key methodological lessons (codified in memories + preflight)

1. **chi²-at-truth + driver-truth = two separate checks.** chi²-at-truth (internal mock consistency) is necessary but not sufficient. Driver-truth (the fit driver's hardcoded constants/priors reproduce chi²/N≈1 on the mock) catches mock-driver mismatches that chi²-at-truth alone can't. See `feedback_mock_driver_consistency.md`.
2. **PyAutoLens centre convention is `(y, x)`.** Lenstronomy uses named `center_x, center_y`. Mapping: `centre = (center_y, center_x)`. Naming this explicitly in the regen script (commit `2c7308b`) prevented re-introducing the bug.
3. **Single source-of-truth dict for mock generators.** Avoid the "simulator + JSON dump drift" failure mode (DSPL bug). One Python dict feeds both `al.Galaxy(...)` and `json.dumps(...)`.
4. **Every mock generator MUST have a chi²-at-truth assertion.** Preflight Step 6 verifies this across all 5 current generators.
