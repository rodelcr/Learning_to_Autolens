## 3. The main post-compaction task: Mod 04/05 + Solutions/04/05 notebook cleanup

### Goal

Replace every `aplt.subplot_fit_imaging(fit=result_X.max_log_likelihood_fit)`
call with a `show_result("<stage>")` call that reads directly from
`results/<stage>/`. Same pattern Mod 09 already uses (see
`Modules/09_MGE_Linear_Light_Profiles/09_mge_linear_light_profiles.ipynb` last
code cell — the `show_result()` def + `show_result("mass_total[1]")` call).

### Why

1. Fixes the nbconvert rendering bug from the 2026-04-21 audit
   (`Modules/10_Cluster_Computing/AUDIT_2026_04_21.md`): reconstructing
   `result.max_log_likelihood_fit` from a Nautilus cache renders garbage
   residuals under some execution contexts. Loading the saved
   `fit_subplot.png` sidesteps the reconstruction entirely.
2. Makes local `nbconvert --execute` fast: no fit cells need to run, all
   visualizations read from disk.
3. Aligns Mod 04/05 with Mod 09's clean pattern.
4. Cluster→laptop pull produces a deterministic render: whatever's in
   `results/<stage>/fit_subplot.png` is what the reader sees.
