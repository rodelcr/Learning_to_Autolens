## 2. Headline result this cycle — compound_lens upgrade ladder

Started the cycle with v3 (no shear, max|res|=6.18σ). Ended with EPL
fit that's **clean PASS on both bars**:

| Variant | n_params | chi²/N | max\|res\| | log_Z | Δ vs v4 | Verdict |
|---|---|---|---|---|---|---|
| v3 (Iso, no shear) | 31 | 0.727 | 6.18σ | +30,705 | -151 | borderline SUSPECT |
| v4 (Iso + shear) | 33 | 0.693 | 4.40σ | +30,856 | baseline | borderline PASS |
| **EPL** (PowerLaw + shear) | 34 | **0.661** | **3.82σ** | **+31,000** | +144 | **PASS both bars** |
| PIX (Iso + fixed mass + RectAdaptImg src) | 3 + ~400 inv | 0.672 | 4.49σ | +31,107 | +250 | log_Z winner, no max\|res\| Δ |

EPL recovered γ' = 2.142 ± 0.020 — **7σ from γ'=2** (Isothermal). The
mass profile is slightly steeper than SIS, matching Auger+10 SLACS
γ' ≈ 2.08 ± 0.16. PowerLaw is the right next-rung upgrade for this
mock; pixelisation is overkill (mock source IS a smooth Sersic so
nothing extra to capture).

Notebook `03_compound_advanced_models.ipynb` documents the comparison
with explicit "PIX is not always the right answer" framing.

## 3. New tooling shipped this cycle

### `compound_multiplane_plot.py` — compact compound-lens visualiser

PIL-level cropping of autolens's `fit_N.png` files to produce a single
figure with shared image-plane panels (Data/Model/Residual/Chi²) on
top and one Source Plane (Zoomed) per source plane on the bottom.

Run manually after a fit:
```bash
python Modules/10_Cluster_Computing/scripts/compound_multiplane_plot.py \
    --results-dir Examples/compound_lens/results/compound_direct_epl_fit/ \
    --plane-labels "source plane @ z=0.8 (relay)" "source plane @ z=1.7 (true source)"
```

## 4. fit_example_compound_lens.py — five fit parts

```bash
sbatch --export=ALL,EXAMPLE=compound_lens,FIT_EXTRA_ARGS=--part=<X> ...
```

| `--part=` | What it fits | Wall time |
|---|---|---|
| `direct` | v4 — Isothermal + shear + SersicCore source. 33 params. | 1h35m |
| `direct_epl` | EPL slope free + shear + SersicCore. 34 params. | 3h45m |
| `direct_pix` | 2-stage: v4-config stage 1 → fixed mass + RectAdaptImg(20×20) + Adapt-reg stage 2 | 1h + 5m (stage 2 is 3-param) |
| `slam_effective` | Single-effective-deflector slam_v2026 | 1h53m |
| `slam_staged` | True 2-deflector inline 3-stage chain | 3h+ |
| `all` | All five sequentially | ~10h |

Production CPU paths use `--mem=64G` (default in slurm). `direct_pix`
needs `--mem=128G` because export_results post-phase OOMs at default.
