## 7. Methodology lessons codified this arc

1. **Lens-light flexibility is the critical bottleneck for BCG-scale lenses**,
   not source-plane flexibility. v2 (1-Sersic uniform) and v3 (1-Sersic
   informed) both failed pathologically; v4 (3-Sersic) succeeded immediately.
   N+23's pipeline ordering (Light pipeline → Mass pipeline, 3-Sersic
   selected as prerequisite) reflects this — the lens-light correction
   IS prerequisite to mass-model fitting on BCG-scale lenses.

2. **N+23 does NOT use σ_v in their likelihood** — verified via ar5iv §1
   only mentions Smith+2017 σ_v as motivating background; §3-§4 use only
   imaging-based degeneracy-breakers (counter-image suppression §4.2 +
   mass-light coaxiality §4.3). Our Phase 3 σ_v Jeans factor is our
   methodological extension, not a paper reproduction. Spec 05 design + plan
   rewritten to reflect this.

3. **Prior widening must be paired with mass-light tying**. v2 had untied
   centres + narrow priors → fit drifted to fit contaminating flux. v3 had
   untied centres + Gaussian-anchored priors → collapsed to spherical
   isothermal. v4 had tied centres + same priors → succeeded. Widening
   alone doesn't help if the model has degenerate degrees of freedom.

4. **autolens 2026.4 AnalysisImaging defaults to JAX-on**. Combining it
   with non-JAX-traceable analyses (like our Jeans factor) via
   `af.FactorGraphModel` crashes the JAX trace. Always pass
   `use_jax=False` explicitly when combining.

5. **NFW.potential_2d_from is not implemented in autolens 2026.4**. Any
   decomposed-mass fit will crash at the visualizer step unless monkey-
   patched. The fit itself runs (samples are written before visualize),
   so results are recoverable, but the slurm job exits with error code 1.

6. **Bayes-factor cross-class consistency is the right primary diagnostic**
   for paper-faithful M_BH detection — not single-mass-class detection
   significance. PL +SMBH ΔlnZ alone could be a PL-specific artifact;
   detecting it ALSO in decomposed (ΔlnZ=+29.87) confirms the SMBH is
   real, not a model artifact. This is N+23's §3.8 logic exactly.
