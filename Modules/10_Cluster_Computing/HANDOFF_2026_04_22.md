## 6. Key design patterns to preserve

### The skip-guard pattern (Mods 04/05/06 + Examples/compound_lens)

```python
_HAVE = (RESULTS_ROOT / "<stage>" / "summary.json").exists()
_FORCE = os.environ.get("LTA_RUN_HEAVY", "").lower() in ("1", "true", "yes")
if _HAVE and not _FORCE:
    print("[local] Using committed Cannon results — skipping the fit.")
    result = None
elif not _HAVE and not _FORCE:
    print("[local] No committed results yet. Set LTA_RUN_HEAVY=1 or submit on Cannon.")
    result = None
else:
    result = search.fit(model=model, analysis=analysis)
```

### The branched VIZ pattern

```python
if result is not None:
    aplt.subplot_fit_imaging(fit=result.max_log_likelihood_fit)

    show_result("<stage>")
```

### The skill-verdict template (Mod 11 §4)

Every fit gets a 4-line numeric summary + 6-panel walk + overall verdict.
See `Modules/11_Physical_Mass_Models/11_physical_mass_models.ipynb` for the
canonical form. Always open Source Plane + Lens Light Subtracted, not just
Residual + chi² — they are what catch Pattern C (SLaM cascade carrying
forward mesh collapse).

### Four named failure patterns (memory/project_fit_failure_patterns.md)

- **Pattern A**: Rotational mirror-image local optimum (fit-time bug)
- **Pattern B**: autolens sign-convention drift between versions (data-time bug)
- **Pattern C**: SLaM cascade — one bad stage poisons priors downstream
- **Pattern D**: Documentation-code dataset mismatch

Invoke `/autolens-fit-diagnostics` when evaluating any fit output.
