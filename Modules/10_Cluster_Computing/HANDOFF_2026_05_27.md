**Mass-shape correctness** (the key audit Rodrigo caught):
- §3.6-§3.8 (analytic): formula `θ_E_pl = θ_E_target · (1−f_BH)^(1/(γ−1))` — preserves M(<θ_E) exactly.
- §3.9 (PyAutoLens): linear formula `θ_E_SIE_new = θ_E_target − θ_E_BH²/θ_E_target` — exact for SIS, 0.94% deviation for SIE e1=0.25 on base_class 2.
- §3.10 (PyAutoLens, low-ellipticity EPL): 0.153% outer-ring deviation.

Inside θ_E, all M(<r) differ by up to f_BH·θ_E (the BH's contribution) — full M(<r) equality is mathematically impossible for point-mass vs smooth-PL comparison. Callout in §3.6 explains precisely.

**Critical-curve / caustic detection** (PyAutoLens sections): no `al.Tracer.critical_curve_from()` API in 2026.4.13.6, so the helper computes Jacobian eigenvalues via numerical Hessian of the deflection field + extracts zero-contours via matplotlib + maps to source plane via `al.Grid2DIrregular`. For base_class 2 ±SMBH: noBH gets 1 tangential curve (no radial — SIE is isothermal), +SMBH gets 1 tangential + 2 radial (BH adds radial critical curve). For §3.10 EPL with γ=1.7, the radial caustic is detected only partially — numerical noise — defer with the rest of fake-0206 fidelity until updated paper.
