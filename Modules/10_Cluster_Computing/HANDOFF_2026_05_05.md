## 4. truth_fc TIMEOUT diagnosis path (next-session priority 1)

The three R5_truth_freecosmo jobs all TIMED OUT at 48h without convergence. Possible causes (in order of likelihood):

1. **Compound-zoo R5 mocks have the same member-light bug we just found in cluster_scale.** The mock generator may have left some component (lens light? source ellipticities?) unmodeled in the truth_anchored driver. Diagnostic: run the same chi²-at-truth-evaluation locally as we did for cluster_scale (see `/tmp/cluster_truth_check.py` pattern in `f8471bb`). If chi²/N at literal truth is > 5, there's a model-vs-mock gap. Should be a 5-min check per mock.
2. **The cosmology dimensions (Om₀, w₀) genuinely need more steps to converge.** The compound-zoo §15 result (R5_freecosmo with wide priors) showed cosmology gets driven by lens-model misfit; truth_anchored should NOT have that issue, but if the secondary deflector mass is railing in the prior, cosmology may absorb the residual. Diagnostic: pull the partial samples from the timed-out runs and inspect the sample distribution at the 48h checkpoint.
3. **Multi-plane PowerLaw is too expensive at this n_live.** The non-truth-anchored R5 fits took 13h; truth-anchored adds 2 cosmology dimensions but the per-call cost should be similar. 48h not converging suggests the chain isn't finding the basin, not that it's exploring slowly.

**Recommended next session step:** apply the cluster_scale diagnostic recipe (manual chi²-at-truth eval) to mocks 2/3/5 truth_freecosmo to determine whether this is a model-fix issue or a budget issue. If model-fix: same fast-PASS pattern as cluster_scale. If budget: resubmit at 96h or accept these as research-in-progress for v0.93 too.
