## 5. Cannon environment notes — climb cycle gotchas

Two fixable infrastructure issues surfaced during the climb cycle:

1. **`export_results.py` failed** at the slurm-job tail because it required
   `Examples/<EXAMPLE>/` to exist as a directory. Used `EXAMPLE=compound_lens_zoo_climb`
   (no such Examples dir). Workaround: ran export manually with
   `--example compound_lens_zoo` after each job. **Permanent fix:** allow the
   slurm script to use a redirect alias when `Examples/<EXAMPLE>/` is missing,
   or simplify by always using the canonical example directory name.

2. **Multi-plane fits emit `fit_2.png` not `fit.png`/`fit_1.png`**, so the
   default `export_results.py` skipped them. Patched to walk `fit_[2-9]*.png`
   as fallback — already in the local copy, but **needs to be pushed to
   Cannon** so future R3+ runs auto-export cleanly.

Both fixes are small; recommend a small "infrastructure" commit at the
start of the next session.
