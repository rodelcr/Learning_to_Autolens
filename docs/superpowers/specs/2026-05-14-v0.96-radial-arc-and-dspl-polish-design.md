## 4. Architecture

### 4.1 Module 15 — Radial Arcs & Caustic Topology

Path: `Modules/15_Radial_Arcs_Caustic_Topology/15_radial_arcs.ipynb` + Solutions variant.

Five sections (~25 cells, pedagogical only; executes in <60 s on laptop, no Cannon dependency):

1. **Radial vs tangential caustics.** Jacobian eigenvalue decomposition: tangential critical curve where λ_t = 1 − κ + γ = 0; radial critical curve where λ_r = 1 − κ − γ = 0 (equivalent: 2κ̄ − κ = 1 from Schneider+92 §5). Source-plane caustics are images of the critical curves under the lens equation. Visualisation: convergence map → critical curves → caustics for a power-law lens at varying γ.
2. **Magnification asymptotics.** Near a tangential caustic μ ∝ 1/d (linear divergence); near a radial caustic μ ∝ 1/√d (square-root divergence). Implication: radial arcs at finite μ → source is *inside but near* the radial caustic. Worked example with extended source.
3. **Why radial arcs constrain γ′.** Inner mass slope γ′ controls the radial-caustic radius; radial-arc length and position are direct probes of inner slope. Derivation: for power-law κ ∝ r^(1-γ), the radial caustic radius scales as a known function of γ. Cite Sonnenfeld+13.
4. **The γ′–M_BH degeneracy.** Adding a central point mass shifts inner slope effectively but not identically to γ′ — they're *nearly* degenerate for typical Einstein-spiral configurations. What breaks the degeneracy: (a) stellar kinematics σ_v(R) integrating different radii than the lensing constraint; (b) multiple sources at different impact parameters; (c) high-resolution central imaging (Λ-CDM ULMP regime, JWST NIRCam diffraction-limited).
5. **Hand-off.** Forward references to `Examples/radial_arc_smbh/` for the practical methodology and Module 13 for the kinematic break. Note that Learning_to_Lens Module 15 is planned but not required for this notebook to ship.

Reference texts: S92 §5, Congdon & Keeton Ch. 6, Sonnenfeld+13, Auger+10, Shajib et al. spiral paper.

#### Mock geometry

Einstein-spiral analog. Source near radial+tangential caustic intersection — produces both a tangential arc (~1″ Einstein-radius scale) and a radial arc segment (~0.3″ from centre). 80×80 px @ 0.05″/px (HST WFC3-IR-like), exp_time=1000 s, bg_rms=0.01.

Truth model:
- Lens galaxy at z_l = 0.7 (matches AGEL spiral targets):
  - Mass: `al.mp.PowerLaw` with `einstein_radius=1.4″`, `slope=1.85` (sub-isothermal), `ell_comps=(0.1, 0.0)`, `centre=(0, 0)`
  - Shear: `al.mp.ExternalShear` with `gamma_1=0.02, gamma_2=-0.01`
  - Central: `al.mp.PointMass` with `einstein_radius_BH = sqrt(4 G M_BH D_ls / c² D_l D_s)` → for M_BH=1e10 M☉, gives ~0.01″ angular Einstein radius (small but detectable in inner slope)
  - Lens light: `al.lp.Sersic` n=4, R_e=1.2″, intensity=1.0 (for chi²-at-truth realism; not part of the mass fit unless we add a `--part=with_lens_light`)
- Source at z_s = 1.5: `al.lp.Sersic` n=1.5, R_e=0.2″, near radial caustic intersection.
- Cosmology: FlatLambdaCDM(70, 0.30).

Self-consistency check at the end of `generate_mock.py`: chi²-at-truth ≤ 1.5, max|res| ≤ 5.0σ.

Auxiliary mock: synthetic σ_v aperture measurement at R_eff with σ(σ_v) = 10 km/s. Used by `--part=with_kinematics`.

#### Driver `fit_example_radial_arc_smbh.py`

CLI: `--part={direct, no_pointmass, with_pointmass, with_kinematics, all}`

- **`direct`** — power-law + shear + source, γ′ free, no point mass. Establishes the imaging-only inner-slope posterior. ~9 free params, n_live=200.
- **`no_pointmass`** — sanity baseline: same model, γ′ pinned to 2.0 (isothermal). Bayes-factor reference. ~8 free.
- **`with_pointmass`** — adds `al.mp.PointMass` at the lens centre. Free `M_BH` (or equivalently `einstein_radius_BH`). Tests γ′ + M_BH joint posterior; expected to show the partial γ′–M_BH degeneracy that Module 15 §4 describes. ~10 free.
- **`with_kinematics`** — `with_pointmass` model + Jeans-σ_v likelihood term combined via `af.FactorGraphModel`. This is where the γ′–M_BH degeneracy gets broken. Same Jeans machinery as `kinematic_h0_break` (build once, ship in two examples). ~10 free + tied via the σ_v likelihood.
- **`all`** — sequential 1→2→3→4 with prior passing.

Cannon wall budgets: direct ~2h, no_pointmass ~2h, with_pointmass ~3h, with_kinematics ~4h on 32 cores. Total `all` ~12h. Submit on `siag_lab` partition with `--mem=128G` per the 2026-05-11 OOM-pattern documentation.

`tag_suffix` parameter on each `build_search_*` (per 2026-05-11 checkpoint-hygiene rule) — if we ever swap the synthetic mock for a real target, the suffix isolates the checkpoints.

#### Notebook `01_radial_arc_smbh.ipynb`

~30 cells:

1. **Physics motivation** (§1–2 forward refs to Module 15). Why radial arcs constrain γ′. The Einstein-spiral observational signature.
2. **Load the mock** + visualise: data, noise, PSF, source-plane caustics overplotted on the convergence map.
3. **Fit setup**: model construction with priors, build each `--part` model.
4. **Run audit** of the `direct` fit: 6-panel residual walk (Module 11 cross-link), chi²/N + max|res| against the noise floor.
5. **γ′ posterior**: 1D marginal, compare to truth (1.85). Compare to isothermal (γ=2.0) Bayes factor — the no_pointmass vs direct comparison.
6. **M_BH posterior** (`with_pointmass`): joint γ′ + M_BH corner plot. Show the degeneracy from Module 15 §4 in posterior form.
7. **Kinematic break** (`with_kinematics`): same corner plot with σ_v constraint applied. Show degeneracy breaking + final M_BH posterior tightness.
8. **Bridge to real AGEL targets**: forward to README §"Next steps to C".

#### README §"Bridge to real AGEL targets (depth C)"

Explicit checklist (no new code in v0.96; this is documentation):

- [ ] **Empirical PSF.** Real lens fields have variable PSFs; build one from drizzled HST exposures using bright isolated stars in the same frame (`agel_real_target` pattern).
- [ ] **Neighbor light masking.** Einstein-spiral mass lives at the centre of a bright lens galaxy; neighbours within ~3″ contribute light that must be masked or modelled.
- [ ] **Real σ_v measurement pipeline.** ppxf on IFU data (KCWI / LLAMAS). σ_v aperture matching: lensing and kinematics integrate different scales — handle the aperture matching explicitly.
- [ ] **Spectroscopic vs photometric z_l, z_s.** Real systems have measured redshifts but with finite precision. Propagate z uncertainty into the M_BH posterior.
- [ ] **Multi-band joint fit** (HST WFC3 F814W + JWST NIRCam F200W typical). Source colour gradients matter at radial-arc scales.
- [ ] **Inner-slope systematics budget.** Compare γ′ posterior with PSF mismatch ablations, mask radius variation, prior tightness ablations.
- [ ] **Reference comparison.** Compare M_BH posterior against Shajib et al. (first Einstein spiral) and Ferrami et al. (DESJ0206) recipes. Same physics, different mass-decomposition choices.
- [ ] **Target picks.** Suggested AGEL spiral targets in order of recommendation: DESJ0206 (Ferrami paper baseline), AGEL104041, AGEL143408, AGEL144640 — all have HST + IFU data per the Observing Logs.

### 4.3 `kinematic_h0_break` driver

`Modules/10_Cluster_Computing/scripts/fit_example_quad_time_delay.py` adds `--part=joint_fit_h0_kin`.

Pattern: `af.FactorGraphModel(af.AnalysisFactor(AnalysisPoint), af.AnalysisFactor(AnalysisImaging), af.AnalysisFactor(AnalysisKinematics_custom))`. The kinematics analysis is a custom subclass following `autolens_workspace_latest/scripts/guides/advanced/custom_analysis.py` template (the parallel-agent survey confirmed there's no built-in `al.AnalysisKinematics`; we write one).

Jeans solver: spherical anisotropic Jeans equation integrated to give σ_v(R_eff) prediction for any (mass profile, β_aniso, R_eff) tuple. Module 13 has the theory; this driver lifts it into an autofit `Analysis.log_likelihood_function`. Single-file implementation, ~200 lines, dependency-free Python + numpy + autolens (no jampy etc. — we want zero extra deps).

The same `Analysis` class is consumed by `Examples/radial_arc_smbh/` `--part=with_kinematics`.

- Pattern B (checkpoint figure-of-merit mismatch): never reuse `unique_tag` when mock/priors change.
- Memory (OOM at 32 workers): `--mem={128G simple, 160G mid, 192G heavy}` per the 2026-05-11 memory-budgeting table.
- Autolens visualizer xp= bug: the two-layer shim already lives in `fit_example_mge_to_physical.py`. **If a new visualizer crash hits another driver, lift the shim into a shared module** `Modules/10_Cluster_Computing/scripts/_autolens_compat.py` and import from each driver. ## 10. Open questions / decisions to revisit

- **Lens light in radial_arc_smbh.** Should the fit model the Sersic lens light (more realistic, ~5 extra free params) or treat it as masked-out (cleaner)? Default: masked-out for the v0.96 example, with a follow-up `--part=with_lens_light` exercise. Revisit if the masked fit leaves coherent residuals at the centre.
- **SMBH parametrisation choice.** `al.mp.PointMass` is parameterised by Einstein radius of the point mass, not directly by M_BH. The notebook converts post-fit via M_BH = (c²/4G) × θ_E,BH² × D_l D_s / D_ls. Confirm the post-fit conversion before shipping.
- **Aperture for Jeans σ_v.** Match real-IFU practice (KCWI aperture ~1″ × 1″) or use R_eff? Default: R_eff to keep the worked example clean; the C-bridge checklist flags aperture-matching as a real-data systematic.
- **Mock M_BH truth value.** 1e10 M☉ chosen to match Shajib paper (UMBH); verify the angular Einstein radius is detectable at HST pixel scale (0.05″) — currently ~0.01″, requires sub-pixel modelling fidelity from autolens. If undetectable, bump to 5e10 M☉ for tutorial purposes (flagged in README).
