## What this example is for

Strong lenses can detect **dark matter substructure** that is invisible by other means. A small DM subhalo overlapping the lensed source perturbs the image plane in a way that cannot be reproduced by smooth lens models. By fitting both a smooth model and a model-with-subhalo and comparing their Bayesian evidences, we can:

- Decide whether a substructure is present (Bayes-factor > critical threshold).
- Constrain the mass and position of the substructure if present.
- (Sensitivity-mapping mode) Quantify the smallest mass we *could have* detected at each image-plane location.

This is the methodology that produced **the first robust dark-matter substructure detections in strong lenses** (Vegetti+ 2010 MNRAS 408, 1969; Vegetti+ 2012 Nature 481, 341) — and is a flagship test of cold-vs-warm dark matter at galaxy scales.

## Mock data

Generated by `mocks/generate_mock.py`:

| Component | Value |

| External shear | (γ_1, γ_2) = (0.05, 0.05) |
| **Subhalo** | NFW truncated (Duffy+08 M-c), `mass_at_200 = 1e9 M☉`, centre = (+0.5, +0.5)″ |
| Source | SersicCore: I=0.5, R_e=0.1″, n=1.5 |
| Imaging | 110×110 px @ 0.05″/px, exp_time=300s, Gaussian PSF σ=0.05″ |

The subhalo mass `10^9 M☉` is **just above the canonical PyAutoLens detection threshold** for HST-class data (~10^{8.5} M☉, Vegetti+ 2014). This means the detection should be *real but borderline*, perfect for showing how Bayes factors quantify "borderline".

## Methodology (this scaffold)

Two fits, same data:

1. **`smooth` model** — Isothermal + ExternalShear + SersicCore. ~12 free params.
2. **`with_subhalo` model** — same as smooth + `al.mp.NFWTruncatedMCRDuffySph` perturber with free centre and `mass_at_200`. ~15 free params.

Compute Δlog_Z = log_Z(with_subhalo) − log_Z(smooth). Per the **bayesian_model_comparison** Example:

- |Δlog_Z| < 1: inconclusive
- |Δlog_Z| > 5: strong (Trotta scale)
- |Δlog_Z| > 10: decisive

Vegetti+ 2010 found Δlog_Z ≈ +12 for their first detection (in JVAS B1938+666). For our 10^9 M☉ mock, expect Δlog_Z ~ +5–15.

### What this scaffold does NOT do (full pipeline left as extension)

The Vegetti+10 / Despali+18 / PyAutoLens canonical methodology adds several things to the basic two-fit comparison:

- **SLaM source pipeline** with pixelised source — needed because the perturbing signal sits in residuals at the few-percent level that smooth Sersic sources can absorb spuriously. See `autolens_workspace_latest/scripts/imaging/features/advanced/subhalo/{detect,sensitivity}/start_here.py`.
- **Grid-search of subhalo positions** — the subhalo location is multi-modal; a full 2D grid search at each cell ensures Nautilus doesn't miss the global optimum.
- **Sensitivity mapping** — for non-detection cases, what's the smallest mass we *could* have detected at each (y, x)?

The scaffold here is a *starting point* — the two-fit Bayes-factor comparison with a fixed-position-prior subhalo. Adding the SLaM + grid search is the next iteration.

## Exercises

1. **Sensitivity sweep.** Re-generate the mock with subhalo `mass_at_200` of 10^7, 10^8, 10^9, 10^10, 10^11 M☉. Re-run the two-fit comparison at each. Plot Δlog_Z vs mass — at what mass does the detection become decisive (Δlog_Z > 10)? At what mass does it become inconclusive?
2. **Position sensitivity.** Move the subhalo to (0, 0)" (overlapping the lens centre), (1.5, 0)" (outside the Einstein ring), and (0.0, 0.5)" (on the arc). Compare detection significance — where is the lens most sensitive?
3. **False-positive rate.** Generate a smooth-only mock (no subhalo) and re-run the two-fit comparison. Δlog_Z should be near zero or *favour the smooth model* (the with-subhalo model carries an Occam penalty). If you sometimes get Δlog_Z > 5 from a no-subhalo mock, that's a numerical artifact — repeat with higher `n_live` to verify.
4. **Pixelised source.** Replace the parametric Sersic source with a pixelised inversion (mirror compound_lens 03 PIX). The detection significance should *increase* — pixelised sources reveal smaller-amplitude perturbations. This is the Vegetti+10 observation.
5. **Full SLaM grid search.** Implement the canonical pipeline from `autolens_workspace_latest/scripts/imaging/features/advanced/subhalo/detect/start_here.py`. ~10× more code but is the publication-grade methodology.
