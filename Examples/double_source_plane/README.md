# Example: Double Source-Plane Lens

## Status

◐ **In progress** — notebooks + mocks + Cannon driver shipped; v0.94 staged-chain (`beta_chain`) in flight on Cannon (job 11214940 launched 2026-05-07). Cosmographic posterior on (Ωₘ, w₀) pending Stage 2 convergence.

## Problem

A single lens galaxy at z_L deflects **two sources at different redshifts** — typically z_S1 ∼ 0.5–1.0 and z_S2 ∼ 1.5–3.0. The ratio of Einstein radii for the two source planes constrains the cosmological distance ratio

$$\beta = \frac{D_{l\,s_1} \, D_{s_2}}{D_{l\,s_2} \, D_{s_1}}$$

which is **independent of H0** (the H0 in numerator and denominator cancels) and probes the dark-energy equation of state via the angular-diameter-distance integrand. This is the **cheapest cosmography from strong lensing** — no time-delay observations required.

This is **not** a compound lens (see [`../compound_lens/`](../compound_lens/)) — there's only *one* deflector, but two source planes.

## Method

The fit is a 3-stage approach (per `02_beta_cosmography.ipynb`):

1. **Direct fit** (`--part=direct`): lens + 2 sources at fixed cosmology, known z_s1, z_s2. Recovers lens model + source structures.
2. **β-cosmography Stage 1** (`--part=beta_fixedcosmo`): lock lens/source shapes from (1), free the redshift z_s1 only (β ↔ z_s1 1-1 mapping at fixed cosmology). Truth-anchored on lens centre + shear.
3. **β-cosmography Stage 2** (`--part=beta_freecosmo_v3`): unlock cosmology with `TruncatedGaussianPrior` on (Ωₘ, w₀). Uses Stage 1 lens/source posteriors as priors — **chained** via `result.model.galaxies`. Bounds prevent Nautilus from sampling unphysical (Ωₘ ≤ 0 or extreme phantom-DE w₀) regions which crashed the autolens FlatwCDM integrator in v0.93.

The recommended one-shot pipeline is `--part=beta_chain` which runs Stage 1 → Stage 2 in a single submit.

## Running on Cannon

```bash
sbatch --time=96:00:00 --mem=64G --cpus-per-task=32 \
       --job-name=dspl_beta_chain \
       --export=ALL,EXAMPLE=double_source_plane,FIT_EXTRA_ARGS=--part=beta_chain \
       Modules/10_Cluster_Computing/scripts/submit_cannon.slurm
```

The chain runs Stage 1 (24h budget) → Stage 2 (48h budget) in one job. Stage 2 inherits Stage 1's lens/source posteriors via PyAutoFit's `result.model` API — see `Modules/10_Cluster_Computing/scripts/fit_example_double_source_plane.py` `build_beta_chain` for the prior-passing pattern.

## v0.94 methodology fix

v0.93's `--part=beta_freecosmo_v2` stalled (Pattern A: `f_live=1.0` throughout 48h, log_Z=−70k decreasing). Diagnosis: `cosmology.Om0 = af.GaussianPrior(mean=0.30, sigma=0.10)` allowed Ωₘ ≤ 0 sampling, which crashed the autolens FlatwCDM angular-diameter integrand. v0.94's fix (commit `bd275eb`): replace `GaussianPrior` with `TruncatedGaussianPrior(lower_limit=0.05, upper_limit=0.60)` on Ωₘ and `(lower_limit=-1.6, upper_limit=-0.4)` on w₀. Same fix applied to `compound_lens_zoo` cosmology priors (truth_fc trio).
